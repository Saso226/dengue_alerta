# 🦠 Dengue Alerta - Previsão de Pressão Epidemiológica

## 📌 Visão Geral
Projeto desenvolvido para detectar crescimento anormal de notificações de dengue e estimar localidades e períodos com maior risco de aumento de casos.

## 🎯 Objetivos
* **Painel Epidemiológico:** Curvas semanais, mapas de risco e alertas de tendência.
* **Detecção de Anomalias:** Identificação de picos epidemiológicos usando técnicas de IA/KDD.
* **Uso de Clima:** Correlação entre temperatura/chuva e casos de dengue.

## 🛠️ Tecnologias Utilizadas
* **Python 3.x**
* **Data Lake Simulado** (Raw / Processed / Final)
* **Pandas** (Tratamento e limpeza de dados)
* **Scikit-Learn** (Detecção de anomalias e séries temporais)
* **Streamlit** (Painel/Dashboard interativo)

## 📁 Fontes de Dados
* **Notificações de Dengue:** DATASUS / SINAN
* **Dados Climáticos:** INMET (Instituto Nacional de Meteorologia) ou API Open-Meteo
